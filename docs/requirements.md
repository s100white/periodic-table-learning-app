# 원소 주기율표 학습앱 요구 사양 명세서

## 1. 프로젝트 개요

이 프로젝트는 대학생 입문자를 위한 비교 중심 원소 주기율표 학습앱이다. 사용자는 표준 주기율표 형태의 화면에서 원소를 탐색하고, 각 원소의 핵심 특성과 실제 활용 예시를 확인하며, 두 원소를 비교해 주기적 경향성과 화학적 차이를 이해할 수 있어야 한다.

초기 개발은 로컬 환경에서 빠르게 진행하고, 이후 GitHub 저장소에 푸시한 뒤 Vercel로 배포한다. 데이터 저장소는 Supabase를 사용하며, v1에서는 사용자 계정이나 학습 진도 저장보다 원소 데이터 관리에 우선 사용한다.

## 2. 목표

- 표준 주기율표 형태를 유지하면서 원소 탐색 경험을 제공한다.
- 원소 상세 정보를 단순 나열이 아니라 학습 가능한 설명과 예시로 제공한다.
- 두 원소를 선택해 주요 성질을 비교하고, 차이가 발생하는 이유를 짧게 설명한다.
- Supabase 기반 원소 데이터 구조를 준비해 이후 콘텐츠 확장과 관리가 가능하게 한다.
- 로컬 개발에서 검증한 뒤 Vercel 배포로 이어질 수 있는 Next.js 기반 앱을 전제로 한다.

## 3. 대상 사용자

주 대상은 일반화학 또는 기초 화학을 배우는 대학생 입문자다. 사용자는 원소 이름과 기호를 일부 알고 있지만, 전자배치, 산화수, 전기음성도, 원자 반지름, 이온화 에너지 같은 개념은 아직 학습 중이라고 가정한다.

설명은 한국어로 제공하며, 전문 용어를 사용하되 처음 배우는 사용자가 이해할 수 있도록 짧은 해설과 실제 예시를 함께 제공한다.

## 4. 핵심 사용자 흐름

1. 사용자는 앱에 접속하면 표준 주기율표를 본다.
2. 검색 또는 필터로 관심 있는 원소를 찾는다.
3. 원소 하나를 클릭하면 상세 패널에서 물성, 전자구조, 화학적 특징, 사용 예시를 확인한다.
4. 비교 모드에서 두 원소를 선택한다.
5. 앱은 두 원소의 주요 성질을 나란히 보여 주고, 차이가 나는 이유를 짧은 학습 설명으로 제공한다.
6. 사용자는 비교 대상을 교체하거나 초기화하면서 다른 원소 조합을 탐색한다.

## 5. 화면 및 기능 요구사항

### 5.1 주기율표 화면

- 표준 원소 주기율표 배치를 기본 형태로 사용한다.
- 각 원소 셀에는 최소한 원자번호, 원소기호, 원소명 또는 영문명을 표시한다.
- 원소 계열은 색상으로 구분한다.
- 검색어 또는 필터 조건에 맞는 원소는 강조하고, 조건에 맞지 않는 원소는 약하게 표시한다.
- 란타넘족과 악티늄족은 표준 주기율표 관례에 맞게 별도 행으로 표시한다.

### 5.2 검색 및 필터

- 원소명, 영문명, 기호, 원자번호로 검색할 수 있어야 한다.
- 다음 기준으로 필터링할 수 있어야 한다.
  - 원소 계열
  - 상온 상태
  - 주기
  - 족
- 검색과 필터는 함께 적용될 수 있어야 한다.
- 검색 결과가 없으면 사용자가 이해할 수 있는 빈 상태 메시지를 표시한다.

### 5.3 원소 상세 패널

원소를 클릭하면 상세 패널에 다음 정보를 표시한다.

- 원자번호
- 원소기호
- 원소명
- 영문명
- 원자량
- 원소 계열
- 주기와 족
- 상온 상태
- 전자배치
- 전기음성도
- 주요 산화수
- 원자 반지름
- 1차 이온화 에너지
- 녹는점
- 끓는점
- 밀도
- 간단한 화학적 특징
- 대표 사용 예시

상세 패널은 사용자가 원소를 바꿀 때 즉시 갱신되어야 한다. 필수 데이터가 없는 항목은 빈 값으로 두지 말고 “데이터 준비 중”처럼 명확한 상태를 표시한다.

### 5.4 원소 비교 모드

- 사용자는 두 원소를 선택해 비교할 수 있어야 한다.
- 비교 대상은 언제든 교체할 수 있어야 한다.
- 비교를 초기화하는 기능을 제공한다.
- 비교 표에는 다음 항목을 포함한다.
  - 원자번호
  - 원자량
  - 원소 계열
  - 상온 상태
  - 전자배치
  - 전기음성도
  - 주요 산화수
  - 원자 반지름
  - 1차 이온화 에너지
  - 녹는점
  - 끓는점
  - 밀도
- 비교 결과에는 두 원소의 차이를 설명하는 짧은 학습 문장을 제공한다.
- 설명은 단순 수치 비교가 아니라 주기적 경향성, 전자배치, 금속성 또는 비금속성 차이와 연결되어야 한다.

### 5.5 학습 보조 콘텐츠

- 원소 상세에는 실제 사용 예시를 1개 이상 표시한다.
- 비교 모드에는 “왜 차이가 날까?” 형식의 짧은 설명을 제공한다.
- 설명은 대학생 입문자 수준에 맞추고, 지나치게 긴 강의문 형태는 피한다.
- 퀴즈, 즐겨찾기, 학습 진도 저장은 v1 필수 범위에 포함하지 않는다.

## 6. Supabase 데이터 요구사항

v1에서 Supabase는 원소 데이터와 학습 설명 콘텐츠를 관리하는 저장소로 사용한다.

### 6.1 `elements`

원소의 기본 정보, 물성, 전자구조 데이터를 저장한다.

필드 예시:

- `id`
- `atomic_number`
- `symbol`
- `name_ko`
- `name_en`
- `atomic_mass`
- `category`
- `period`
- `group`
- `block`
- `state_at_room_temp`
- `electron_configuration`
- `electronegativity`
- `oxidation_states`
- `atomic_radius`
- `first_ionization_energy`
- `melting_point`
- `boiling_point`
- `density`
- `summary`
- `chemical_characteristics`
- `created_at`
- `updated_at`

### 6.2 `element_examples`

원소별 실제 사용 예시를 저장한다.

필드 예시:

- `id`
- `element_id`
- `title`
- `description`
- `context`
- `created_at`
- `updated_at`

### 6.3 `element_comparison_notes`

비교 모드에서 사용할 설명 또는 주기적 경향성 학습 문장을 저장한다.

필드 예시:

- `id`
- `element_a_id`
- `element_b_id`
- `topic`
- `note`
- `created_at`
- `updated_at`

특정 원소 쌍에 대한 설명이 없을 경우, 앱은 원소 데이터의 수치와 계열 정보를 바탕으로 기본 비교 설명을 표시할 수 있어야 한다.

## 7. 기술 및 개발 전제

- 프론트엔드는 Vercel 배포에 적합한 Next.js 기반으로 개발한다.
- UI 언어는 한국어를 기본으로 한다.
- 로컬 개발 초반에는 Supabase 연결 전이라도 seed 데이터 또는 정적 fallback 데이터로 화면 개발이 가능해야 한다.
- Supabase 연결 정보는 환경 변수로 관리한다.
- v1은 로그인 없이 사용할 수 있어야 한다.
- GitHub 저장소 푸시 전까지는 로컬에서 주요 화면과 데이터 흐름을 검증한다.

## 8. 비기능 요구사항

- 데스크톱과 모바일 화면에서 핵심 기능을 사용할 수 있어야 한다.
- 주기율표, 상세 패널, 비교 영역이 서로 겹치지 않아야 한다.
- 원소 셀과 버튼은 클릭 가능한 상태가 명확해야 한다.
- Supabase 데이터 로딩 중에는 로딩 상태를 표시한다.
- Supabase 연결 실패 또는 데이터 조회 실패 시 사용자에게 오류 상태를 표시한다.
- 데이터가 일부 비어 있어도 앱 전체가 깨지지 않아야 한다.
- 색상만으로 정보를 구분하지 않고 텍스트 또는 라벨을 함께 제공한다.

## 9. v1 범위

v1에 포함한다.

- 표준 주기율표 렌더링
- 원소 검색
- 계열, 상태, 주기, 족 필터
- 원소 클릭 상세 패널
- 원소별 실제 사용 예시
- 두 원소 비교 모드
- 비교 결과 학습 설명
- Supabase 기반 원소 데이터 조회
- 로컬 fallback 데이터
- Vercel 배포 가능 구조

v1에서 제외한다.

- 사용자 로그인
- 즐겨찾기
- 개인 학습 진도 저장
- 퀴즈 기능
- 오답 복습
- 관리자 CMS
- 다국어 전환
- 결제 또는 유료 기능

제외 항목은 후속 버전 후보로 남긴다.

## 10. 검수 기준

- 앱 첫 화면에서 표준 주기율표가 의도한 위치와 구조로 표시된다.
- 원소를 클릭하면 해당 원소의 상세 정보가 올바르게 표시된다.
- 검색어 입력 시 관련 원소가 강조되거나 목록이 갱신된다.
- 필터 선택 시 조건에 맞는 원소만 명확히 구분된다.
- 검색과 필터를 함께 사용해도 결과가 일관되게 표시된다.
- 비교 모드에서 두 원소를 선택, 교체, 초기화할 수 있다.
- 비교 표의 수치와 설명이 선택한 원소에 맞게 표시된다.
- Supabase 연결 실패 시 오류 상태가 표시되고 앱이 중단되지 않는다.
- 모바일과 데스크톱에서 주요 UI가 겹치거나 잘리지 않는다.
- 로그인 없이 모든 v1 기능을 사용할 수 있다.

## 11. 후속 버전 후보

- 원소 기호, 원자번호, 계열을 맞히는 퀴즈
- 즐겨찾기 원소 저장
- 학습 진도 저장
- 오답 복습
- Supabase Auth 기반 사용자 계정
- 원소 콘텐츠를 수정할 수 있는 관리자 화면
- 주기적 경향성 시각화
- 산화수, 전자배치, 결합 예시를 더 깊게 다루는 학습 모듈
- 영어 UI 전환
