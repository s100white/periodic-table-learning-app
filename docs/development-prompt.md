# 개발 실행 프롬프트

다음 요구 사양 명세서를 기준으로 원소 주기율표 학습앱 v1을 개발한다.

## 목표

대학생 입문자를 위한 한국어 원소 주기율표 학습앱을 만든다. 사용자는 표준 주기율표에서 원소를 탐색하고, 원소 상세 정보를 확인하며, 두 원소를 비교해 성질 차이와 주기적 경향성을 학습할 수 있어야 한다.

## 구현 지침

- Next.js 기반으로 로컬 개발과 Vercel 배포가 가능한 구조를 만든다.
- UI는 한국어로 작성한다.
- Supabase는 v1에서 원소 데이터 저장소로 사용한다.
- Supabase 환경 변수가 없거나 호출이 실패하면 로컬 fallback 데이터로 앱이 계속 동작해야 한다.
- 로그인, 퀴즈, 즐겨찾기, 관리자 화면은 v1 범위에서 제외한다.
- 주기율표, 검색/필터, 상세 패널, 비교 모드를 첫 화면 안에서 사용할 수 있게 구성한다.
- 모바일과 데스크톱에서 주요 UI가 겹치지 않게 반응형으로 만든다.

## 핵심 기능

1. 표준 주기율표 레이아웃
2. 원소명, 영문명, 기호, 원자번호 검색
3. 원소 계열, 상온 상태, 주기, 족 필터
4. 원소 클릭 상세 패널
5. 두 원소 비교 모드
6. 비교 결과에 짧은 학습 설명 표시
7. Supabase 데이터 조회 실패 시 오류 안내와 fallback 데이터 사용
